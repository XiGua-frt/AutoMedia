# `agent_log_service.py` 日志层说明

## 核心作用

`python-backend/app/services/agent_log_service.py` 是多 Agent 系统的**日志基础设施层**，主要承担 3 件事：

- **异步落库**：将每个 Agent 的执行日志（开始/结束时间、耗时、状态、入参、出参、错误）写入 `agent_log` 表
- **按任务查询**：根据 `taskId` 拉取该任务的完整 Agent 执行日志链路
- **执行统计聚合**：基于日志计算总耗时、各 Agent 耗时、任务总体状态（SUCCESS / RUNNING / FAILED / NOT_FOUND）

它的目标是：**观测性（可追踪） + 可诊断（可定位慢点和失败点）**，同时不阻塞主业务链路。

---

## 这个文件对系统的价值

- **不阻塞主流程**：`save_log_async()` 用 `asyncio.create_task()` 异步写日志，AI 主链路不等待日志落库
- **串联全流程证据**：通过 `taskId + agentName` 能复盘每个阶段做了什么、何时完成、是否失败
- **直接支撑监控面板**：`get_execution_stats()` 返回前端可直接展示的统计 VO
- **便于问题排查**：失败时可快速看到 `errorMessage + prompt + inputData + outputData`

## 数据流转图（Mermaid）

### 1) 写入链路：Agent 执行日志如何入库

```mermaid
flowchart TD
    A[ArticleAgentService 中某个 Agent 开始/结束] --> B[_agent_log_context 构建 log_data]
    B --> C[save_log_async(log_data)]
    C --> D[asyncio.create_task(_save_log)]
    D --> E[_save_log 执行 SQL INSERT]
    E --> F[(agent_log 数据表)]
    E --> G[logger.info: 日志保存成功]
    E -.异常.-> H[logger.exception: 保存日志失败]
```

说明：
- `save_log_async()` 只负责派发异步任务，不等待数据库完成
- `_save_log()` 才是真正执行 SQL `INSERT INTO agent_log ...`
- 即使写日志失败，也不会中断主业务（只打异常日志）

---

### 2) 查询与统计链路：如何生成执行报告

```mermaid
flowchart TD
    A[调用 get_execution_stats(task_id)] --> B[get_logs_by_task_id(task_id)]
    B --> C[SQL SELECT agent_log by taskId and isDelete=0]
    C --> D[(agent_log 数据表)]
    D --> E[rows]
    E --> F[_to_agent_log_vo 转为 AgentLogVO 列表]
    F --> G{是否有日志}
    G -- 否 --> H[返回 NOT_FOUND 统计结果]
    G -- 是 --> I[遍历日志聚合]
    I --> J[totalDurationMs 累加]
    I --> K[agentDurations 按 agentName 记录耗时]
    I --> L[overallStatus 推导: FAILED > RUNNING > SUCCESS]
    J --> M[组装 AgentExecutionStatsVO]
    K --> M
    L --> M
    M --> N[返回给上层/接口]
```

说明：
- 统计不是数据库聚合，而是**应用层遍历聚合**
- `overallStatus` 逻辑优先级：`FAILED` 最高，其次 `RUNNING`，否则 `SUCCESS`

---

## 关键方法速览

- `save_log_async(log_data)`：异步派发日志保存任务
- `_save_log(log_data)`：执行 SQL 入库
- `get_logs_by_task_id(task_id)`：按任务查询日志明细（时间升序）
- `get_execution_stats(task_id)`：聚合执行统计并返回 VO
- `_to_agent_log_vo(row)`：DB Row -> 业务 VO
- `_to_iso(datetime)`：时间字段统一转 ISO 字符串

---

## 一句话总结

`AgentLogService` 是多 Agent 编排系统的**日志观测层**：前向负责“低侵入异步落库”，后向负责“任务级日志回放与统计聚合”。
